# Unified header and context display

The upper bezel and center recess form one screwed glass assembly. The small
control beside the OLED is the global Master Output, with its numeric value;
the Filter section contains the only Low Pass knob. The output meter remains
visible on the upper glass, including the latched clip and pre-master indicators.
The preset name and PRESETS button remain visible.

The header menu gives access to MIDI input channel, Module and Studio views,
and resetting latched clip indicators. These controls use the same processor
bindings and actions as the former dedicated widgets. The OLED retains spectrum,
waveform and contextual views, with its existing click/keyboard navigation.

The appearance requires visual review at supported sizes. Audio, plugin state,
parameter identifiers, master gain semantics and preset data are unchanged.
